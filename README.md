
# SARD Projects

大学のローバー開発サークルで制作・使用した
Pythonプログラムをまとめたリポジトリです。

## 開発内容

### センサー制御
- pHセンサー：電圧取得・pH変換
- 温度センサー：Raspberry Pi / Raspberry Pi Picoを用いた計測
- 土壌水分センサー：測定データの取得
- 九軸センサー：センサーデータの取得

### 分光器
- スペクトルデータの取得
- 波長変換処理
- スペクトルグラフの描画

## 開発環境
- Python
- Raspberry Pi / Raspberry Pi Pico

## 目的
ローバーに搭載するセンサーの制御と、
計測データの取得・可視化に必要な
プログラムを開発・検証することを目的としています。
